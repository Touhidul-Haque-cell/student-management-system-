# Student Management System — Python + SQLite

A beginner-friendly command-line project for a Computer Science graduate.

## Features
- Add student records
- View all records
- Search by name or department
- Update student name
- Delete a student
- Export records to CSV
- Save records in an SQLite database

## How to run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: `python app.py` (or `py app.py` on Windows).
4. Choose a menu option and follow the prompts.

No third-party packages required. The database file is created automatically.
